# Portfólio Nexo

Site estático e responsivo, sem dependências de build.

## Publicar na Vercel

1. Envie esta pasta a um repositório Git ou importe-a diretamente na Vercel.
2. Na configuração do projeto, deixe o campo **Build Command** vazio.
3. Defina o diretório de saída como `.` (raiz) e publique.

Como alternativa, com a CLI: `vercel --prod` dentro desta pasta.
